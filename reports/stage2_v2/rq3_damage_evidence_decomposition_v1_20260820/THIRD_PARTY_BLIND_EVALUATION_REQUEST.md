# RQ3 blind evaluation request — unsent template

Status: **draft only; do not send without explicit authorization**

We seek an independent custodian for a one-shot pixel-semantic building-damage evaluation on five target events (minimum three), all previously unseen by the development team. The locked set must contain at least two events with Damaged support and two with Destroyed support, exclude California 2025 and Jamaica 2025, and pass content plus geographic-range separation from all 14 development events.

The custodian retains event identities if needed, all four-class labels, and the scoring script. Inputs must include the optical/SAR imagery and deployment-available SAR acquisition metadata. Before development training begins, both parties freeze SHA-256 digests for the event list, input manifest, hidden labels, metric script, and written agreement.

The package permits one format-only dry run and one scored disclosure containing F0-C2 plus the selected candidate's C1/C2/C3 predictions. Resubmission is allowed only when no score was computed or disclosed. The custodian should return pixel metrics, building-level Damaged/Destroyed metrics, event macro averages, C2/C3 contrasts, worst-event effects, and the number of improved events.
